# Лабораторные работы

| Папка | Работа | Статус |
|---|---|---|
| [`lab1/`](lab1/) | Консольный генератор экзаменационных билетов с журналом в Excel | Готово |
| [`lab2/`](lab2/) | Десктопное приложение с UI: студенты из Excel, билеты из Word, журнал результатов в Excel | В работе |

Каждая лаба — отдельное .NET-решение со своим `README.md`, планом `PLAN.md` и исходным ТЗ в `docs/`. Общие правила разработки — в [`AGENTS.md`](AGENTS.md).

Требуется .NET SDK 10.0. Сборка и тесты запускаются из папки лабы:

```bash
cd lab1
dotnet test
```
