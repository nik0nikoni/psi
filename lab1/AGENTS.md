# Лабораторная работа 1: консольный генератор билетов

Дополняет общие правила из корневого `AGENTS.md`.

- Решение: `TicketGenerator.sln`; тесты запускаются командой `dotnet test` из папки `lab1/`.
- Консольный ввод/вывод скрыт за `IConsole`; зависимости собираются вручную в `Program.cs`.
- Хранилище — `journal.xlsx` в текущем рабочем каталоге.
- UI-тестами на `FakeConsole` проверяй сценарии из раздела «Проверка результата» ТЗ.
- E2E-тестами запускай реальный процесс приложения и проверяй stdout и содержимое `journal.xlsx`. Не отправляй ESC в E2E-ввод.
